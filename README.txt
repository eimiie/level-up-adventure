LEVEL UP ADVENTURE — iPHONE WITHOUT A MAC

This version is a Progressive Web App (PWA). It runs in Safari and can be added to the iPhone Home Screen so it behaves much more like an app.

IMPORTANT:
It is not an App Store app. You do not need a Mac or Apple Developer membership.

EASIEST FREE SETUP WITH WINDOWS:
1. Create a free GitHub account at github.com if you don't already have one.
2. Create a new PUBLIC repository, for example: level-up-adventure.
3. Upload index.html, manifest.json, sw.js, and this README.txt.
4. In GitHub, open Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select the main branch and the root folder, then Save.
7. GitHub will give you a web address such as:
   https://YOUR-USERNAME.github.io/level-up-adventure/
8. Open that address in Safari on your iPhone.
9. Tap the Share button.
10. Tap "Add to Home Screen".
11. Tap Add.

Now "Level Up Adventure" appears as an icon on the iPhone and opens without normal browser controls.

The game saves progress locally in the browser using localStorage.
